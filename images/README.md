### ⚠ 아틀라스에서 반드시 지킬 것

**상자를 원본 글자 범위 밖으로 넓히지 마세요.** 512×512 아틀라스는 스프라이트가
빽빽하게 붙어 있어서, 한글이 길다고 세로로 늘려 잡으면 **옆 칸을 덮어써서**
엉뚱한 화면에 한글 조각이 나타납니다(실제로 스토리 선택 화면 제목 옆에
`께`·`이` 가 튀어나온 적이 있습니다). 한글이 길면 글자를 줄이거나 문구를
짧게 다듬으세요.

**여러 벌(`[('dark',…), ('local',…)]`)을 쓸 때 상자 번호는 원본에서 매겨집니다.**
`build_all` 이 모든 벌의 상자 목록을 먼저 원본에서 계산한 뒤 적용하므로,
앞 벌이 그림을 바꿔도 번호가 밀리지 않습니다.

### 조서 이름표 — `tools/chosho.py`

`detective_chosho_*` 는 범인 이름 후보 목록입니다. 처음에는 한자 한 글자가
한 칸인 줄 알았는데, 11장을 모두 재보니 **글자 사이 6px / 이름 사이 40px 이상**
이라 **이름 하나가 세로 한 줄(스프라이트 1개)** 이었습니다. 그래서 글자별로
쪼개지 않고 이름 전체를 한 줄로 넣습니다.

`chosho.cells()` 가 글자 칸을, `chosho.groups()` 가 열·이름 단위로 묶어 주므로
이름 목록만 순서대로 주면 좌표가 자동으로 나옵니다. `一` `二` 처럼 납작한
글자가 빠지지 않도록 최소 높이를 4px 까지 낮춰 뒀습니다.

## 한글화 파이프라인

```
image_text.json + tools/atlas_maps.py
      ↓  build_images.py   원본 위에 한글 렌더 → 원본 팔레트로 GIM 재인코딩
image_payloads.pkl
      ↓  build_iso.py      아카이브에 반영 → ISO
```

### ① `image_text.json` — 알파 채널이 있는 단순 이미지

```json
{
  "NF/adv_hint_bg_marun":        {"ko": "마루노우치의 헛추리"},
  "SI_A/marunouchi_result_good": {"ko": ["마루노우치의 헛추리", "해결!"]},
  "NF_A/ol_title_000":           {"ko": "지금까지의 줄거리", "mode": "v"}
}
```

- `ko` 가 문자열이면 한 덩어리, 리스트면 행별(알파 수평 투영으로 행 자동 검출)
- `mode: "v"` 는 세로쓰기
- 글자 색·테두리 색·위치·크기는 **원본에서 자동으로** 따옵니다

### ② 챕터 타이틀 — `tools/vtitle.py`

480×272 불투명 배경에 세로쓰기 제목이 구워져 있어 알파를 쓸 수 없습니다.

1. **밝기 120 이상**을 글자로 보고 마스크를 만든다
2. 주변 색을 확산시켜 메우고(`inpaint.fill`), 다른 자리의 고주파 질감을 얹어
   매끈해 보이지 않게 한다(`inpaint.retexture`)
3. 밝기 165 마스크로 제목·저자·`完`·`解決編` 상자를 찾아 같은 자리·같은 색으로
   한글 세로쓰기

핏자국 위의 `解決編` 도 글자만 지워지고 핏자국은 남습니다.

### ③ UI 아틀라스 — `tools/atlas.py` + `atlas_maps.py`

512×512 아틀라스는 글자·아이콘·버튼이 섞여 있어 상자를 자동으로 찾고
**번호로 한글을 붙이는** 방식입니다.

```python
python -c "import atlas,numpy,PIL.Image as I; \
  atlas.report(numpy.asarray(I.open('common/common0.png').convert('RGBA')),'dbg.png')"
```

- 상자 목록(좌표·내부 빈칸)이 찍히고 `dbg.png` 에 번호가 그려집니다
- 그 번호로 `tools/atlas_maps.py` 의 `MAPS` 에 한글을 적습니다

```python
'common_scenario5': {
    2: '게임 진행 방법',                          # 상자 그대로
    3: ('게임 진행 방법', 354, 482, 182, 202),   # 좌표를 직접 지정(괄호 장식 보존)
    (1, 2): '두 줄 이상인 문단은 이렇게 — 한글 길이에 맞춰 다시 흘려 넣습니다',
    'st': ('새 상자', 226, 397, 359, 383),        # 번호 없는 자리
}
```

- 값이 **5원소 튜플**이면 그 사각형을 그대로 쓰고(글자로 다시 조이지 않음),
  괄호·아이콘 장식을 건드리지 않아야 할 때 씁니다
- 키가 **튜플**이면 여러 줄 문단 → 한글 길이에 맞춰 줄바꿈을 다시 계산
- 지우기는 **세로 한 줄씩** 배경색을 구해 채우므로 형광 띠·그라데이션이 남습니다

#### 글자 종류 (`MAPS[name]` 을 리스트로 주면 여러 벌을 순서대로 처리)

| 종류 | 쓰는 곳 |
|---|---|
| `dark` (기본) | 밝은 판 위 어두운 가로 글자 — 상자를 자동으로 찾음 |
| `light` | 어두운 판 위 흰 가로 글자 |
| `dark-v` / `light-v` | 위와 같되 **세로쓰기** |
| `local` / `local-v` | 좌표를 직접 준 상자만. 글자색을 **상자 안 대비로** 정하므로 버튼처럼 배경과 밝기 차가 작은 자리에 씁니다 |

```python
'detective_mode4': [('local-v', {
    'a1': ('조서 완성', 196, 232, 232, 324),   # (한글, x0, x1, y0, y1)
    'q4': ('문4', 433, 453, 240, 300),
})],
```

흰 글자에 검은 테두리가 있으면 자동으로 감지해 같은 두께로 테두리를 그립니다.

### ④ 세로쓰기 한 페이지 — `atlas.build_note` + `NOTES`

도입 안내문처럼 열 여러 개에 글이 흐르는 화면입니다. 원문을 밝기로 지워
(`inpaint.fill`) 배경을 메운 뒤, 한글을 **열 격자에 다시 흘려 넣습니다**.

```python
NOTES = {'introduction_note': ('한글 전문…', (84, 26, 396, 250),
                               [383, 352, 320, 288, 256, 224, 192, 160, 128, 96], 17)}
#                               글자영역             열 중심 x(오른쪽부터)        글자크기
```

`build_note` 는 넘친 글자 수를 함께 돌려주므로 0 인지 확인하면 됩니다.

## GIM 포맷 (재삽입 시 필요)

```
"MIG.00.1PSP\0" + 4바이트, 0x10 부터 블록 체인
  블록 헤더: u16 id, u16 _, u32 size, u32 nextOffset, u32 dataOffset
  id: 0x02 root / 0x03 picture / 0x04 image / 0x05 palette
```

이미지 헤더(0x30바이트):

```
0x00 u16 headerSize   0x04 u16 format   0x06 u16 tiled(swizzle)
0x08 u16 width        0x0A u16 height
0x0C u16 bpp          0x0E u16 pitchAlign   0x10 u16 heightAlign
```

이 게임은 전부 **format 5 (Index8, 256색 팔레트) + tiled=1**,
`pitchAlign=16`, `heightAlign=8` 입니다.

### ⚠ 반드시 지킬 것 ① — 픽셀 데이터 시작 오프셋

헤더 크기(`+0x18` = 48)와 **픽셀 데이터 시작 오프셋(`+0x1C` = 64)은 다릅니다.**
헤더 크기 뒤부터 읽으면 **16바이트 앞서 읽게 되어 이미지 전체에 가로 줄무늬**가 생깁니다.

```
data_start = u32 at (block_data + 0x1C)     # 헤더 크기(+0x18)가 아님
```

팔레트 블록(0x05)도 같은 규칙입니다. 이 게임의 팔레트는
**RGBA8888 256색**(`format=3`, `bpp=32`, `width=256`)이라 항목당 4바이트입니다.

### ⚠ 반드시 지킬 것 ② — pitch 정렬

```
pitch  = ceil(width * bpp / 8 / 16) * 16
height = ceil(height / 8) * 8
```

이 값으로 swizzle 을 풀고 나서 `[:height, :width*bpp/8]` 로 잘라내야 합니다.
폭이 16의 배수가 아닌 이미지 **75장**이 여기 해당합니다.

### swizzle

PSP 표준 방식으로 **16바이트 × 8행 블록** 단위로 섞여 있습니다.
블록을 `(bh, bw, 8, 16)` 으로 보고 `transpose(0,2,1,3)` 하면 풀립니다.

## 재삽입 시 참고

- 원본이 Index8 이므로 **원본 팔레트를 그대로 재사용**합니다(`tools/gimenc.py`).
  왕복 무손실을 확인했습니다.
- 크기(width/height)는 바꾸지 않습니다. 화면 배치가 스크립트에 좌표로 잡혀 있습니다.
