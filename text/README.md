# Trick × Logic Season 1 — 일본어 원문 추출 (번역용)

`Trick x Logic Season 1.iso` 에서 게임 내 일본어 텍스트 **20,524개**를 추출했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `_index.json` | 메타데이터, 표시 한계, 번역 지침, 파일 목록 |
| `TU/NF/FW/KM/SI/BH/BJ .json` | 시나리오별 본편 |
| `*_A.json` | 각 시나리오의 추리(Answer) 파트 |
| `common.json` | 메뉴·튜토리얼·인포메이션 등 공통 UI |

## 엔트리 구조

```json
{
  "id": "TU/TU_prologue/0007",
  "archive": "TU.bin",
  "file": "./script/TU/TU_prologue.bin",
  "index": 7,
  "category": "prologue",
  "speaker_hint": "yosikawa",
  "ja": "원문",
  "ko": "",
  "chars": 12,
  "max_chars": 44,
  "group": { "id": "TU_prologue/g0003", "size": 3, "pos": 1, "ja": "그룹 전체 원문" },
  "loc": { "len_off": 617, "str_off": 621, "orig_bytes": 25 }
}
```

- **`ko`** — 여기에 번역을 채웁니다. 비워두면 원문 유지로 처리합니다.
- **`loc`** — 재삽입용 좌표. **수정 금지.** 20,524건 전부 이 좌표로 원문이 정확히 복원되는 것을 확인했습니다.
- **`speaker_hint`** — 직전 캐릭터 표시 명령에서 유추한 "화면에 나온 인물"이라 실제 화자와 다를 수 있습니다. 참고용입니다.

## ⚠ 반드시 지켜야 할 두 가지

### 1. 대사는 조각으로 쪼개져 있습니다

문장 단위가 아니라 **조각 단위**로 저장돼 있습니다(루비·강조·키워드 표시 때문).
`prologue` 는 76%가 6자 이하이고, 문장부호로 끝나는 조각은 절반도 안 됩니다.

**조각별로 번역하면 문장이 망가집니다.**
`group.ja` 가 있으면 그 그룹 전체를 한 문장으로 보고 번역한 뒤, 각 조각의 `ko` 에 나눠 담으세요.

조각 경계를 원문과 똑같이 맞출 필요는 **없습니다.** 문자열마다 길이 필드가 따로 있어
길이를 자유롭게 바꿀 수 있으므로, 한 조각에 몰아넣고 나머지를 빈 문자열로 둬도 됩니다.

전체 20,524 조각 = 11,468 문장 그룹 (단독 조각 36.8%).

### 2. 길이 제한 — 대사창은 44자

| 구분 | 한계 | 근거 |
|---|---|---|
| ADV 대사창 | **44자** (22자 × 2줄) | 아래 참조 |
| 소설/설명 | 엔트리의 `max_chars` | 해당 파일 원문의 관측 최대 |

44자 근거:

- 대사 전용 파일(`_answer_begin.bin`, `_giveup.bin`, `_marunouchi.bin` 등)의 원문 최대가 **정확히 44자**
- 길이 분포가 44자(114개) → 45자(39개)로 급감. 전체의 93.2%가 44자 이하
- 스크린샷 실측 대사창 폭 ≈ PSP 367px, 전각 advance 17px → 21~22자/줄. 22 × 17 = 374px 로 일치

**한글은 전각이라 일본어와 폭이 같습니다.** 글자 수를 그대로 세면 됩니다.

45자 이상(1,395개, 6.8%)은 전부 시나리오 본체와 `question`/`tips`/`inspiration` 으로,
소설 모드나 전체화면 텍스트를 쓰므로 `max_chars` 를 따르면 됩니다.

### 3. 개행을 넣지 마세요

원문에는 **개행·제어문자가 하나도 없습니다.** 게임이 자동으로 줄을 바꿉니다.
번역문에도 `\n` 을 넣지 마세요.

## 기술 정보 (재삽입용)

문자열 저장 형식:

```
u32 length (널 종료 포함)  |  cp932 바이트열  |  0x00
```

일본어 문자열 146/146 이 이 형식과 일치함을 확인했습니다. 길이 필드가 있으므로
번역문이 원문보다 길어도 됩니다(뒤쪽 오프셋 재계산 필요).

경로: `ISO → PSP_GAME/USRDIR/data/*.bin (SECTPACK) → ./script/**/*.bin (PRCS)`

아카이브/폰트 포맷 상세는 `../font_extract/README.md` 참조.
